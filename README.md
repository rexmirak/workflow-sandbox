# Workflow Sandbox

A minimal text-based repository for maintaining project planning, operational notes, and release information through a controlled Git workflow.

## Repository Structure

- `roadmap.txt` — project priorities and planned work.
- `team-notes.txt` — shared operating notes and collaboration conventions.
- `AGENTS.md` — repository instructions for automated coding agents.
- `CLAUDE.md` — repository context for Claude-based development workflows.

Changes should be scoped, reviewable, and integrated through the repository's established workflow.
