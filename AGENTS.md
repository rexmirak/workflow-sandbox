# Repository Instructions

- Keep changes limited to the requested scope.
- Preserve existing content unless the task explicitly requires modification.
- Use Conventional Commits.
- Work on a dedicated branch for non-trivial changes.
- Inspect the final diff before proposing integration.
- Run available repository checks before finishing.
- Do not bypass required status checks or repository rules.
- Do not force-push shared protected branches.
- Escalate destructive or ambiguous changes for human review.
